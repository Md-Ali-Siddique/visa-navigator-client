# Visa Navigator

**Live site:** https://visa-navigator-site.web.app

Visa Navigator is a portal for checking visa requirements, applying online and tracking every application from one dashboard.

## Features

- Browse all visas with country photo, visa type, processing time, fee, validity and application method.
- Filter the All Visas page by visa type.
- View full visa details, including required documents and age restriction, and apply through a pop-up form.
- Add your own visas, then update or delete them from the My Added Visas page.
- Track your applications, search them by country name and cancel any of them.
- Secure login and registration with email and password or Google, with password validation and protected routes that survive a page reload.
- Dark and light theme toggle, fully responsive on mobile, tablet and desktop.
- Animated home page using React Simple Typewriter, React Awesome Reveal and React Tooltip.

## Technologies

React, Vite, Tailwind CSS, daisyUI, React Router, Firebase Authentication, Axios, SweetAlert2, React Toastify, Express, MongoDB.
